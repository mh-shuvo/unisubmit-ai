## Symptom

"The abstract must be confined to a single page" failed on every submission
longer than one page, regardless of how long the abstract actually was.

## Root cause

`max_pages` and `min_pages` were measured against the whole document while the
rule named a target section. The measurement was correct and the rule was
correct; they were about different things.

## Fix

Scope the span to the target through `_section_page_span`, so a page limit on a
section is measured over that section's pages.

## Verified

A 30-page submission with a one-page abstract now passes the rule it previously
always failed.

## Tests

`tests/test_format_validation_rules.py :: SectionScoping.test_section_page_limit_is_not_measured_on_whole_document`,
with `test_document_page_limit_still_fails` as the guard that document-wide
limits were not loosened by the fix.

## For the thesis

T2. A validity problem rather than a correctness one: every number the engine
computed was right, and the result was still wrong, because the unit of
measurement did not match the unit the rule was about. Pairs with
[DEF-011](DEF-011.md), the same fault on a different quantity, which is what
makes it a class rather than an incident.
