# DEF-047: every HTML page fails with 500 after the Starlette 1.x upgrade, and no test rendered a page

**ID:** DEF-047
**Legacy:** none (introduced and found on branch `phase-1-tooling-layout-migrations`, before merge)
**Kind:** defect
**Status:** fixed
**Severity:** blocking
**Class:** dependency-api-drift
**ODC:** Interface, Incorrect; trigger: Lateral Compatibility
**Component:** `services/core/unisubmit/main.py` :: every `templates.TemplateResponse(...)` call (21)
**Found:** rehearsing the upgrade in an isolated compose project (task P1.12): migrations and the worker came up, and `GET /` returned 500 with `TypeError: unhashable type: 'dict'`
**Added:** 2026-11-14
**Fixed in:** commit `64556cd` on branch `phase-1-tooling-layout-migrations`
**Test:** `services/core/tests/integration/test_pages.py` :: `PageRenderingTests`
**Theme:** T5

---

## Symptom

The web app starts, then answers every page (home, logins, dashboards, admin
pages) with "Internal Server Error". Redirects and file downloads still work.

## Root cause

Task P1.1 replaced the unpinned and partly pinned requirement files with one
lock file, which moved the web app from FastAPI 0.115 / Starlette 0.46 to
FastAPI 0.162 / Starlette 1.10. Starlette 1.0 removed the deprecated call form
`TemplateResponse(name, context)`; the signature is now
`TemplateResponse(request, name, context)`. Every page used the old form, so
the context dictionary arrived as the template name and Jinja's cache lookup
failed on it.

Two safeguards missed it:

- **Tests.** The suite posted forms and followed redirects but never rendered
  a page, so 97 tests passed on a web app with no working page.
- **Types.** mypy reported all 21 calls in task P1.4, and they were put in the
  legacy baseline as noise.

## Reproduction

```
docker compose -p rehearsal up -d --build     # this branch, before the fix
curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:18000/      # 500
```

## Fix

All 21 calls use `TemplateResponse(request, name, context)`.
`PageRenderingTests` opens every page without path parameters, plus the
submission and template-version pages, as the role that may see it: public,
student, unit admin and Super Admin. Red before the fix (4 of 4),
green after.

## For the thesis

T5, `dependency-api-drift`, beside [DEF-004](DEF-004.md): the code did not
change, the library under it did. A lock file makes upgrades deliberate, but the first lock is itself an
upgrade. The example also argues against treating a type checker's legacy
baseline as noise without reading it: the errors in the baseline were the
defect.
