# DEF-017: double spacing could not be measured, so the rule had no passing path

## Symptom

The `line_spacing` rule had no PASS path at all. Every compliant thesis carried
a permanent WARNING, and no document could clear it.

## Root cause

Spacing was sampled within a MuPDF block, pairing lines with
`zip(block_lines, block_lines[1:])`. MuPDF starts a new block once the baseline
gap passes roughly 1.5 em, measured at 1.41 to 1.63 times the font size across
nine sizes, so on a double-spaced page every line landed in a block of its own
and the pairing yielded nothing.

At 12 pt the last grouped gap is 18.75 pt while the rule needs 20.64 pt, so
`estimated_line_spacing` was `None` on every page and the rule always took its
"could not estimate" path. The 0.8 to 3.0 sample window already accepted 2.0;
the requirement was never rejected, only never reached.

A second fault compounded it: doubt was reported too eagerly. A cover page, a
blank leaf or an index carries no running prose and so has no spacing to
measure, and warning on those made the warning permanent for any compliant
thesis.

## Fix

Sample spacing over the page's body lines in reading order, and replace the
block boundary with a horizontal-overlap test, which is what actually
distinguishes one column of text from the next. Warn only when no page in the
document could be measured, so a wholly unmeasurable document still warns and
the never-silently-pass guarantee from [DEF-009](DEF-009.md) holds.

## Verified

Submission #3 went from 39 PASS / 1 WARNING to 40 PASS / 0 WARNING, compliance
97.9% to 100%.

## Tests

`tests/test_format_validation_rules.py :: PdfMeasurement` for the measurement
and `LineSpacingReporting` for the warning policy, including
`test_document_with_nothing_measurable_is_still_flagged`. Each was confirmed red
by reverting only its own fix.

## For the thesis

T2, and the clearest case of the register's sharpest category. This is not a
strict rule or a usually-failing rule: no input could satisfy it, because the
measurement contradicted the requirement. An unsatisfiable rule is invisible in
aggregate statistics, since a 0% pass rate looks like a population that does not
comply, and it was found by trying to build a compliant document rather than by
examining results. That detection method is itself a contribution.
