## Symptom

None observed. A page on another site in the same registrable domain (for
example another `*.university.edu` site) could submit forms as a logged-in
admin, and any page can log a user out with an image tag.

## Root cause

State-changing routes rely on the session cookie alone. The cookie is
`SameSite=Lax`, which stops most cross-site form posts in current browsers but
not same-site ones, and `GET /student/logout` and `GET /admin/logout` change
state on a GET.

## Reproduction

```html
<img src="https://unisubmit.example.edu/admin/logout">   <!-- logs the admin out -->
```

## Fix

Every form renders `{{ csrf_field(request) }}`, a hidden field holding a
random per-session token (task P4.2). `verify_csrf` is a dependency of the
whole router: every POST must carry the token in the form or in an
`X-CSRF-Token` header, compared in constant time, or it gets 403. Logout is
a POST from a small form; `GET /student/logout` and `GET /admin/logout`
answer 405. Login starts a new session, so a token obtained before signing
in is void after it.

## Verified

`test_every_post_route_checks_the_csrf_token` lists POST routes without the
dependency and is red when the router dependency is removed;
`test_post_without_the_token_is_refused`,
`test_post_with_another_sessions_token_is_refused`,
`test_logout_by_get_is_not_possible` and
`test_every_page_form_carries_the_token`.

## For the thesis

the remaining gap is a stated limitation rather than an assumption.
