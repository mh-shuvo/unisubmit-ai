# DEF-041: forms carry no CSRF token and logout is a GET

## Symptom

None observed. A page on another site in the same registrable domain (for
example another `*.university.edu` site) could submit forms as a logged-in
admin, and any page can log a user out with an image tag.

## Root cause

State-changing routes rely on the session cookie alone. The cookie is
`SameSite=Lax`, which stops most cross-site form posts in current browsers but
not same-site ones, and `GET /student/logout` and `GET /admin/logout` change
state on a GET.

## Reproduction

```html
<img src="https://unisubmit.example.edu/admin/logout">   <!-- logs the admin out -->
```

## What closing it requires

A per-session CSRF token in every form, checked by a dependency on every
POST, with logout moved to POST and a test that fails when any POST route
lacks the check (task P4.2).

## For the thesis

T8. Minor, because `SameSite=Lax` already blocks the common case; recorded so
the remaining gap is a stated limitation rather than an assumption.
