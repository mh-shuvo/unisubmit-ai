# DEF-038: guideline parsing and indexing run inside the admin's HTTP request for up to 25 minutes

**ID:** DEF-038
**Legacy:** none (restructuring plan, problem 3; task P3.5)
**Kind:** defect
**Status:** open
**Severity:** major
**Class:** timeout-misalignment
**ODC:** Timing/Serialisation, Incorrect; trigger: Logic/Flow
**Component:** `app/main.py` :: `index_guideline`; `app/ai_service_client.py` :: `parse_guideline_profile` (1,500 s), `index_template` (300 s)
**Found:** architecture review; the "Parse and index" button awaits both AI calls before responding
**Added:** 2026-11-14
**Fixed in:** not fixed
**Test:** none
**Theme:** T5

## Symptom

After "Parse and index guideline", the admin's browser waits with no feedback
for as long as the local model takes to parse the guideline, up to 25 minutes.
A reverse proxy or browser with a shorter timeout ends the request first; the
admin clicks again and the model parses the same guideline twice, while
validation jobs wait behind it on the same model.

## Root cause

`index_guideline` awaits `parse_guideline_profile` (client budget 1,500 s) and
then `index_template` (300 s) inside the request. The caller's budget, the
browser's or a proxy's, is shorter than the work it waits on, which is the
`timeout-misalignment` pattern of [DEF-005](DEF-005.md) and
[DEF-007](DEF-007.md) one hop further out. It is also the one route still
excluded from the [DEF-025](DEF-025.md) guard.

## Reproduction

```
# as a unit admin: upload a long guideline and press "Parse and index";
# the request stays open until the model finishes parsing
```

## What closing it requires

Parsing and indexing become queue jobs handled by the worker, and the
template-version page shows their status (task P3.5). The queue first needs a
job type, which arrives with the generalised `jobs` table in Phase 3.

## For the thesis

T5. The fix is the same one that already serves validation: long model work
belongs in the queue, where it is serialised with the other model work instead
of competing with it from a request handler.
